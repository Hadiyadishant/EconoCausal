# EconoCausal

Simple React/Vite frontend scaffolding dashboard.

## Components

- Navbar.jsx - navigation between Dashboard, Upload Data, and Budget Settings.
- UploadData.jsx - CSV upload UI with basic client-side file validation.
- BudgetSettings.jsx - campaign budget and maximum-discount settings.
- CSS files keep styling separate from JSX.

## Required package

Install React Router:

```bash
npm install react-router-dom
```

Then run:

```bash
npm run dev
```
